## 使用技術
- 言語: C#
- フレームワーク: Unity
- その他: Git, Adobe Photoshop(イラスト制作、ロゴ制作)

## なぜ作ったのか(動機・課題意識)
これまでの学習成果を活かし、短期間で1つのプロダクトを完成させる体験を目的に開発しました。  
仕様をシンプルに絞り込めるカジュアルゲームとして着手し、最後まで作りきることを重視しています。

## 操作方法
左クリック:ジャンプ  
クリック1つのみで簡単に遊べるようにしました。

## 工夫した点・学んだこと 
・ゲームバランスに関する値をインスペクターから調整できるようにしたことで、実務でプログラマー以外でも手軽に調整できる設計にしました。  
・トラブル防止と安全な開発運用のため、Gitによるこまめな履歴管理(粒度の細かいコミット管理)を徹底しました。  
・従来知っていた「背景オブジェクト自体をスクロール移動させる手法」から「Quad（テクスチャのUVオフセット移動）」へ実装方法をアップデートし、新しい技術を自主的にキャッチアップして改善しました。  
・レスポンシブな設計のため、画面のアスペクト比が変わってもUIやプレイヤーが画面外に見切れないよう、アンカー設定や位置調整を最適化しました。
